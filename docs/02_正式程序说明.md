## 3. 空中端程序

`wind_tx_realtime`、`wind_tx_test` 和 `wind_tx` 共用同一个 `src/tx/main.cpp`。它们分别通过 `REALTIME_MODE` 和 `COMMISSIONING_MODE` 选择0.5秒实时演示、2秒快速联调或60秒正式测量。启动时关闭 Wi-Fi 和蓝牙，初始化 SEN0639 与 SX1268。

参数如下：

```cpp
constexpr uint32_t kReportPeriodMs = 60000UL;
constexpr uint32_t kSensorWarmupMs = 1500UL;
constexpr uint16_t kSampleIntervalMs = 200U;
constexpr uint16_t kFinalSampleCount = 25U;
constexpr uint16_t kTestSampleCount = 10U;
constexpr uint32_t kTestReportPeriodMs = 2000UL;
constexpr uint16_t kRealtimeSampleCount = 1U;
constexpr uint32_t kRealtimeReportPeriodMs = 500UL;
```

| 环境 | 样本数 | 发送间隔 | 发送后状态 | 用途 |
|---|---:|---:|---|---|
| `wind_tx_realtime` | 1 | 约 0.5 s | 保持运行，不深睡 | 短时间实时讲解演示 |
| `wind_tx_test` | 10 | 约 2 s | 保持运行，不深睡 | 桌面联调、距离测试 |
| `wind_tx` | 25 | 约 60 s | 进入深睡 | 正式实测、风筝搭载 |

采样阶段使用 Welford 在线算法统计平均值与总体标准差，同时记录最小值、最大值、有效样本数、平均原始量和错误数。

发送后执行：

```cpp
radio.sleep(true);
sensorWire.end();
SPI.end();
esp_sleep_enable_timer_wakeup(sleepUs);
esp_deep_sleep_start();
```

深睡时间按本周期已经消耗的时间扣减，使上报间隔约为 60 s。

## 4. 地面端程序

地面端持续运行并调用 `startReceive()`。DIO1 中断只设置收包标志，主循环读取数据，避免在中断内进行复杂操作。

接收成功后：

1. 校验 LoRa CRC；
2. 按 `WV1` 解析 11 个空中端字段；
3. 获取 RSSI 和 SNR；
4. 输出 13 列串口记录；
5. 刷新 OLED；
6. 重新进入接收状态。

串口表头：

```text
protocol,node,seq,avg,min,max,sd,n,raw,batt_mv,status,rssi_dbm,snr_db
```

## 5. 数据包

```cpp
struct WindPacket {
  char nodeId[13];
  uint32_t sequence;
  float averageMps;
  float minimumMps;
  float maximumMps;
  float standardDeviationMps;
  uint16_t validSamples;
  uint16_t averageRaw;
  uint16_t batteryMv;
  uint16_t status;
};
```

示例：

```text
WV1,KITE01,128,6.420,6.100,6.830,0.210,25,2475,4360,0,-62.0,9.5
```

网页用 `seq` 统计可能的丢包，用 `status` 判断传感器异常，用 RSSI/SNR 显示无线链路质量。

## 6. 网页服务

`dashboard/start_dashboard.bat` 调用 PowerShell 启动器，后者选择 PlatformIO 自带 Python 或系统 Python，以无窗口方式运行：

服务就绪后自动打开浏览器。页面点击“连接串口”后，以 115200 baud 读取地面端。

## 7. 编译和烧录

```powershell
# 空中端0.5秒实时演示程序
pio run -e wind_tx_realtime -t upload

# 空中端快速联调程序
pio run -e wind_tx_test -t upload

# 空中端正式程序
pio run -e wind_tx -t upload

# 地面端正式程序
pio run -e wind_rx -t upload

# 查看地面串口
pio device monitor -b 115200
```

若无法进入下载模式：按住 BOOT，点按 RESET，松开 BOOT 后重新 Upload。

## 8. 正式使用流程

1. 需要0.5秒实时显示时，给空中板烧录 `wind_tx_realtime`；一般联调时烧录 `wind_tx_test`；
2. 给地面板烧录 `wind_rx`；
3. 两块板都接好 410–493 MHz 天线；
4. SEN0639 接到空中端 GPIO41/42；
5. 地面板 USB 接电脑；
6. 双击 `dashboard/start_dashboard.bat`；
7. 页面点击“连接串口”，选择地面端 COM 口；
8. `wind_tx_realtime` 模式下网页约每 0.5 秒收到一条记录；`wind_tx_test` 模式下约每 2 秒收到一条；
9. 联调通过后，给空中板重新烧录 `wind_tx`，确认网页约每分钟收到一条记录；
10. 正式放飞和续航测试只能使用 `wind_tx`；`wind_tx_realtime` 功耗和信道占用较高，只用于短时间演示。

## 9. 修改注意事项

- 修改频率、带宽、SF、编码率或 Sync word 后，两端都要重新烧录；
- 修改 WV1 字段后，要同步修改地面端、`dashboard/protocol.js` 和协议测试；
- `batt_mv` 必须用万用表校准后才可作为电池电压；
- 15 m/s 以上只会报告饱和，不能得到更高风速；
- 完全断电后序号重新开始。
