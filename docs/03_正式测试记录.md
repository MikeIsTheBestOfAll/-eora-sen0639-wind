# SEN0639 LoRa 风速遥测正式版测试记录

版本：V1.1

更新日期：2026-11-19

## 1. 记录原则

本文件记录 `wind_tx_realtime`、`wind_tx_test`、正式版 `wind_tx`、`wind_rx` 和网页服务。编译通过与实物验收分开记录，没有原始日志的项目不得写成已经通过。

## 2. 已完成验证

### 2.1 正式固件构建

工具链：PlatformIO Core 6.2.0、Espressif32 6.6.0、Arduino-ESP32 2.0.14。

| 环境 | 结果 | RAM | 应用分区 Flash |
|---|---|---:|---:|
| `wind_tx_realtime` | PASS | 45,184 / 327,680 B（13.8%） | 711,365 / 1,310,720 B（54.3%） |
| `wind_tx_test` | PASS | 45,184 / 327,680 B（13.8%） | 711,485 / 1,310,720 B（54.3%） |
| `wind_tx` | PASS | 45,332 / 327,680 B（13.8%） | 718,201 / 1,310,720 B（54.8%） |
| `wind_rx` | PASS | 21,644 / 327,680 B（6.6%） | 336,649 / 1,310,720 B（25.7%） |

结果：均成功编译、链接并生成 `firmware.bin`。

### 2.2 网页协议和服务

| 项目 | 命令 | 结果 |
|---|---|---|
| WV1 协议解析测试 | `node dashboard/tests/test_protocol.cjs` | PASS |
| Python 服务脚本语法 | `python -m py_compile dashboard/serve_dashboard.py` | PASS |
| 本地网页 HTTP | `http://127.0.0.1:8765/` | 已验证可返回 HTTP 200 |

### 2.3 实物功能观察

已有演示观察到风速读数随吹气/气流变化，LoRa 地面端可向电脑输出数据，网页能够显示协议字段。由于没有保存带时间戳的串口日志和参考仪器数据，此项仅记为功能观察，不作为精度、距离或续航验收。
